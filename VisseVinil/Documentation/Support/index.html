Perguntas Frequentes

O aplicativo não abre ou falha após abrir. O que devo fazer?

Se você não tiver uma coleção salva, tente apagar o aplicativo e instalá-lo novamente. Caso tenha uma coleção salva ou o problem persistir, entre em contato explicando o seu aparelho, versão IOS e conte se atualizou o aplicativo recentemente

O aplicativo está disponível para Android?

Não. VisseVinil atualmente está disponível apenas para dispositivos IOS.
